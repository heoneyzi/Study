> 🗓️ 2025-06-12 · LVLM 객체 환각 스터디 (1단계, 팀 프로젝트)

[할루시네이션 개요 ② — Language Prior 관련](../01_foundations/03_language_prior_overview.md)

위에 일단 관련해서 이미지 보는 게 적어지는 것을 해결하는 방법을 찾아봤음

> - CoT를 사용할 수 있을까? 사용하는 것이 이득일까?
>
> 꽤나 많은 모델에서 CoT를 사용하는 것을 볼 수 있었음. 물론 환각에서는 아니긴 한데, LLM도 추론 모델이 뜨면서 이미지를 어떻게 보느냐는 것도 추론적으로 할 수 있기 때문인가?? (아직 잘 모름… Help…)
>
> 만약 무언가 이미지에서 건드려야한다면 CoT를 사용하는 것도 나쁜 방법은 아닐 것 같은 느낌??

> - 뭔가 일관성이 있어야할 것 같은 느낌
>
> 우리가 이미지에서 제대로 보게 하는 것 + 이미지를 많이 보게 하는 것을 할 건데, 이게 너무 독립적인 느낌이면 그냥 짜붙이기한 느낌일 것 같은 느낌이랄까..? 아닌가?
>
> 그래서 이미지에서도 어텐션의 재분배를 중점으로 했으면, 이미지 + 텍스트에서도 어텐션의 재분배 느낌으로 가는게 좋을 것만 같은 느낌? 그래야 느낌있게 적을 수 있지 않을까 하는…

> - 갑분 아이디어
>
> 성배형이랑 대충 이얘기를 했는데, 자기였으면 그냥 LLM 선에서 연구를 했을 것 같다고 하더라고.
>
> LLM + 이미지 Captioning과 비교하는 거를 얘기를 하기는 했어. 그냥 LLM만 쓰는 문제로 치환하겠다는거지.
>
> 근데 이걸 잘 사용할 수 있을 것 같은 느낌? 결국 이미지를 가져오는게 문제니까 Hallucination 유무라도 판단할 수 있는 잣대로 사용할 수 있지는 않을까 하는…
>
> 추가적으로 생각해본 거는…
>
> LLM만을 이용한 것과 이미지만을 사용한 것과 비교하는 방법은??
>
> 베이식하긴 한데… LLM만으로 나올 다음 토큰과, 이미지만 봤을 때의 어텐션을 뭔가 사용할 수 있지 않을까 하는??
>
> 이거는 아직 좀 더 로직이 필요할듯…

> - Decoding 방법
>
> 꼭 Greedy를 쓸 필요성?
>
> 난 사실 무조건 Greedy(Softmax Top1)을 쓰는 줄만 알았는데, 아닌 경우가 Hallucination에 많이 있더라고!
>
> Beam Search 등을 야무지게 사용할 수 있을까??
>
> 사실 아직 적재적소가 언제 쓰는건지를 느낌이 안와서… 일단 이거는 브레인 스토밍 바이브로 적어본거긴 해

> 💡 어찌보면 가장 중요할 것 같은데.
>
> 내가 정리했던 논문 중에 가장 마지막 빨강색 논문! 이거는 좀 유심히 읽어봐야할 듯. 일단 봤던 논문 중에서 Prompt Aware로 넣는 이미지를 다르게 한다는 개념 자체가 처음 본 거라서, 여기 좀 더 집중해서 읽어볼 필요가 있을 듯! 나도 아직 다 못 읽긴 했는데, 나중에 읽고 다시 정리해볼게 ㅎ
>
> 형도 셤 끝나면 이것부터 읽어보는게 좋을듯!!!
