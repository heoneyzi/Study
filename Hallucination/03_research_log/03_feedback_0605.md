#### Image Token Attention 관련

지헌이가 하고 싶었던 것: 사람처럼 보자

<p align="center"><img src="assets/73f1863e_01.png" alt="figure"></p>

실제로 친구가 “\~\~ 글자 보여?”하는 말에 나는 수많은 길거리의 간판을 스캔하고 찾아낸다. 이때 나는 간판을 덩어리로 확인을 하고 그 덩어리들의 후보 속에서 찾는다. 특히나 덩어리를 볼 때도 첫글자만 본다. 여기서 영감을 얻었다.

그대로 LVLM에 비유를 하자면, 덩어리를 본다 = object를 본다, 첫 글자를 본다 = object 내에서도 핵심 부분을 본다

처음에 냈던 아이디어: 원본 그림, object 그림, object 제외 그림 이 3개를 이용해서 3중으로 로짓을 바꾸는 것.

원본 VS Object 제외 → Object가 필요한가?에 대한 선택

Object만 → object에서도 어디를 중점적으로 볼 것인가를 선택

여기까지 생각을 했는데 생기는 단점: 어떻게 Inference 단계에서 이걸 선택할 것인가? , 여러개의 Object의 경우는? 이미지를 안봐도 되는 경우는? 이런 문제가 생김

그래서 보완한 점.

여러개의 Object를 볼 수 있도록 Segment하자

그래서 Object n개와 Background 1개를 골라서 총 n+1개의 특징을 추출하자

n+1개의 특징에서 원핫 인코딩을 진행한다. 그래서 n+1개의 차원에 대한 벡터로 만들고, 이를 사용한다.

예를 들어 \[0,0,1,1,0\]이라면 object 3,4를 보는 것.

그렇다면 자연스럽게 이미지의 어디를 보는지 확인해볼 수 있다. 이론상 모두 0인 벡터는 조사 같은 토큰이 튀어나올 때 사용된다면 좋을 것 같다.

> 💡 여기서 + 알파
>
> 그렇다면 object3에 어떻게 집중시킬 것인가?
>
> - 현재 있는 object3에 있는 패치마다 가중치를 고대로 살려서 간다. (더 효율적일 거 같기는 함)
> - object3만 crop해서 이미지를 넣어서 한 번 더 돌린다. 이에 대한 어텐션의 가중치를 구해서, 그걸 살려서 간다. (불필요할까? 그래도 더 확실하긴 할 것 같은 느낌)

일단 가장 중요한 점… 무엇과 비교를 해야할까?

보통의 연구는 이미지의 유무, 노이즈를 준다던지, 특정 토큰 제거 등의 2개를 비교해서 차이를 로짓값으로 사용하는 방법을 사용한다.

그러나 현재 이 방법은 $`2^{n+1}`$개의 feature vector 중에서 어느 것이 가장 맞는 답인지 정해야한다. 지금 생각나는 것은 기존의 그냥 이미지에서 얻은 최종 특징인 $`h_t`$를 사용해야하는 것이 아닐까 고민…

기존의 모델에서 가진 셀프어텐션의 값을 사용하자. 어떻게..? 몰라…ㅋㅎㅋㅎㅋㅎ

근데 애초에 Hallucination을 잡으려고 하는 건데, 기존 걸 대척점이 아닌 힌트로써 사용해도 되는걸까 하는 생각도 듦.

> 💡 다른 논문에서는 특정 토큰에 대한 비율이 임계점을 낮아질 때까지 다시 토큰을 생성하는 논문도 있었음. 어쨌든 추론 과정에서 끝내려면 다지선다형에서 고르는 방향성을 하기는 힘들 것 같다는 느낌.
>
> 만약에 가능하다면, 이런 느낌으로 해야지 추론 과정 선에서 끝내지 않을까
>
> 기존의 모델이 내놓은 셀프어텐션을 힌트로써 사용하던지.<br>→ 예를 들어, 특정 토큰이 크게 나왔으니 그 토큰이 들어있는 object에 집중하게 하자.
>
> 혹은 반대로 Hallucination이라 판단하고 이를 대척점으로써 사용하던지.<br>→ 예를 들어, 환각이라고 판단되었을 때 특정 토큰이 크게 나왔으니 줄이기 위해 다른 object에 집중하게 하자.

만약! 학습을 하게 된다면, 좀 얘기는 쉬워질 듯.

Teacher Forcing을 이용해서 학습을 할 수 있는 간단한 층을 만들어 줄 수 있을 것 같은 느낌? 그니까 매 토큰마다 학습을 할 수 있다…

> 💡 학습이 과연 힘들까..? 학습 없이 추론 과정에서만 결과를 얻을 수 있을까…

#### Image Token 영향력 감소 관련

PAI에서는 이미지 특징에 $`\alpha`$를 곱해서 더 많은 영향력을 주게 했다고 했지만, 이는 결국 토큰이 많이 생성될수록 무의미해짐

그냥 전체적으로 이미지토큰과 텍스트 토큰에 대한 비율을 강제해버리는 것은 안될까?

예를 들어 매 토큰 출력마다 0.5랑 0.5로 보게 셀프어텐션의 값을 조정해버린다던지 하는 것이다.

물론 값을 하이퍼파라미터로 지정하는 것보다는 위에서 기존의 모델에서 가진 셀프어텐션과의 유사도나 이런 걸 이용해서 유동적으로 바꿀 수 있다면 그것도 좋을 느낌?

되게 간단하긴 한데, 너무 Agressive하다는 느낌이 강하다.

그래서 이 방안을 하나의 Head에만 사용하는 것은 어떨까 생각도 해봄. 논문 중에서 특정 Head에서 Hallucination이 많이 일어나는 Head가 있다는 논문을 본 것 같음.

아무튼 하고 싶은 것이 이미지의 특정 지역을 많이 보도록 하고 싶은거니까… 이미지를 보는 비율을 강제적으로 높이는 Head를 넣는 것도 맥락상 의미가 있다고 볼 수 있지 않을까?

그리고 일단 라바를 써야하지 않을까? 현 논문의 트렌드이기도 하고, 셀프 어텐션만 쓰면 된다는 것이 큰 메리트이자 건드릴게 많다고 생각함.
