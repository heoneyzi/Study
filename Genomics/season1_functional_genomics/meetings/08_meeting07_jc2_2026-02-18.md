#### **0218_저널클럽_2회차 : 발표 후 토론 주요 내용**

1. **GLM 성능 평가의 한계점**
    **피어슨 상관계수 기반 평가의 문제**

    - 몇몇 태스크에서 피어슨 상관계수가 0.2-0.3 수준으로 매우 낮음
    - 모든 모델이 제대로 예측하지 못하는 상황에서 상대적 성능 비교의 의미 의문
    - 태스크마다 성능 척도 범위가 상이하여 모델 간 공정한 비교 어려움

    **실험 설계의 공정성 문제**

    - 셀 스페시픽한 특성이 강한 태스크들로 구성되어 파인튜닝 없는 GLM에게 불리한 조건
    - GPN의 경우 저자들이 직접 커스텀 학습시킨 모델 사용으로 다른 기존 모델들과 비교 조건 상이
    - 변인 통제가 충분하지 않아 실험 결과의 신뢰성에 대한 의문
2. **GLM과 원핫 인코딩 비교 실험의 개선 방안**
    **결합 실험의 필요성**

    - 원핫 인코딩과 GLM 임베딩을 각각 사용한 결과뿐만 아니라 두 정보를 결합한 실험 필요
    - 결합했을 때도 성능 향상이 없어야 GLM 임베딩의 무의미함 입증 가능
    - 원핫은 기초적 정보, GLM 임베딩은 고차원 정보로서 상호 보완 가능성 존재

    **파인튜닝과 제로샷 성능의 관계**

    - 파인튜닝 시 성능 향상은 GLM이 기본적 정보를 보유하고 있음을 시사
    - 제로샷에서의 저조한 성능이 GLM의 근본적 한계인지, 활용 방법의 문제인지 구분 필요
3. **GLM 학습 방법론에 대한 근본적 의문**
    **도메인 특성 고려 부족**

    - NLP 모델을 유전체 데이터에 직접 적용하는 것의 한계
    - DNA/RNA 태스크별로 작용하는 언어적 의미가 상이함에도 불구하고 통합 학습의 문제점
    - 한국어를 사용하는 원시부족 비유: 같은 언어라도 맥락과 의미가 다를 수 있음

    **토큰화 방식의 한계**

    - 뉴클레오티드 4가지만으로 구성된 토큰 공간의 의미적 빈약함
    - NLP에서 단어 단위 임베딩이 갖는 풍부한 의미와 달리 DNA/RNA에서는 기능적 단위의 의미 부족
    - Masked Language Modeling이 DNA 서열에서 학습할 수 있는 시맨틱 정보의 한계
4. **논코딩 영역 학습의 어려움**
    **규칙성 부족 문제**

    - 논코딩 영역의 산발적이고 무작위적 특성으로 인한 학습 어려움
    - 중요한 신호가 전체 서열에서 희석되는 현상
    - 코딩 영역과 달리 명확한 문법적 규칙 부재

    **전처리의 필요성**

    - 의미 있는 논코딩 영역(예: Common Enhancer) 선별 후 학습 필요성 제기
    - 전체 서열보다 기능적으로 중요한 부분에 집중한 학습 방법 모색
5. **GLM의 실용적 활용 방안**
    **생성 모델로서의 가능성**

    - 예측 성능은 떨어지지만 새로운 서열 생성에서는 활용 가치 존재
    - 박테리오파지 설계 등 합성생물학 분야에서의 응용 가능성
    - 기존 실험이나 지도학습으로 불가능한 영역에서의 보완적 역할

    **단백질 언어모델과의 차이점**

    - 아미노산의 물리화학적 성질로 인해 단백질 모델이 더 의미 있는 학습 가능
    - DNA/RNA 대비 단백질 영역에서 NLP 아이디어 차용의 효과성 높음
6. **향후 연구 방향**
    **도메인 특화 학습 방법 개발**

    - 기존 NLP 방법론을 넘어선 유전체 데이터 특화 학습 방법 필요
    - 토큰화, 어텐션 메커니즘 등 유전체 특성에 맞는 새로운 접근법 모색

    **지도학습 데이터 활용**

    - AlphaFold처럼 대량의 지도학습 데이터를 활용한 접근법의 우수성
    - 비지도학습보다 태스크 특화 지도학습의 효과성 재확인
