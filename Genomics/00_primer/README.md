# 📘 Primer — biology for ML people

Two short notes written while starting from zero biology: the central dogma (DNA → RNA → protein) and which deep-learning model works at each level. Read them before the journal-club notes.

<details>
<summary><b>🇰🇷 한국어 요약</b></summary>

생물학 비전공자가 Functional Genomics 스터디를 시작하며 정리한 입문 노트 두 편입니다. 핵심은 센트럴 도그마 — DNA에 저장된 정보가 RNA로 복사되고, 그 복사본을 읽어 단백질이 만들어지는 흐름입니다. 도서관에 비유하면 DNA는 대출이 안 되는 원본 서고, RNA는 필요한 쪽만 떠 온 복사본, 단백질은 그 복사본을 보고 실제로 일하는 사람입니다. 두 번째 노트는 각 단계에서 쓰이는 AI 모델(Evo 2, SpliceAI, AlphaGenome, AlphaFold, 단백질 언어 모델 등)을 한 장에 정리합니다.

</details>
