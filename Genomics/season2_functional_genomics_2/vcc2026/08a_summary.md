### 0. 과제 한 줄 요약

익명 세포주 A/B/C의 **비섭동 control 셀만** 주어진 상태에서,<br>**300개 CRISPRi 타겟 × 400셀 × 3컨텍스트 = 360,000행 × 18,533 유전자**의<br>raw 정수 카운트를 예측한다. 챌린지 학습 세트는 **없다** (완전 zero-shot).

채점은 `cell-eval2`의 `vcc2026` 프리셋, 6개 지표를 참조 스케일로 평균한다.<br>**0 = 모든 섭동에 같은 평균 반응을 주는 baseline, 1 = 실제 replicate 실험.**

| 지표 | 무엇을 재는가 |
|---|---|
| `pds_cosine` | pseudobulk 델타의 코사인 랭킹 (호출 수와 무관) |
| `expr_mse_unbiased_capped_norm` | 발현 오차 크기 |
| `de_wilcoxon_lfc_nmae` | log-FC **크기** 오차 |
| `de_wilcoxon_direction_fidelity_yield_raw` | `k / max(n_pred, N_conf)` — 방향 정확도 × 호출 예산 |
| `de_wilcoxon_direction_reach_raw` | 순도 곡선의 깊이 |
| `de_wilcoxon_sig_jaccard` | 유의 유전자 집합의 \` |

최종 순위는 **10/22 공개되는 test set**(컨텍스트 D/E/F, 다른 300개 패널)으로만 결정된다.<br>지금 리더보드는 validation이고, 여기서 얻은 것은 방법론일 뿐 등수가 아니다.

#### 1.2 KIMCHI-1 — STATE 학습 (폐기)

Arc Institute의 STATE를 그대로 태웠다.

- SE-600M **동결** → `X_state` 2,058차원 basal 표현
- State Transition(ST) 116M 파라미터를 Replogle 3개 세포주 **701,428셀**로 학습
- 섭동 표현: ESM2 → 중심화·PCA 256 + control 채널 = 257차원 (300/300 조회 가능)
- 출력: 반응성 상위 2,000 유전자, energy 분포 손실

진단 (`scripts/diagnose_deltas.py`):

|   | hepg2 (본 데이터) | jurkat (미지 세포주) |
|---|---|---|
| corr(실제, 예측) | +0.239 | **+0.056** |
| 과대예측 배율 | 2.26× | **6.43×** |
| 모든 섭동에 공유되는 변화 | 58.1% | 68.0% (실제 9.3%) |

- <b>본 적 있는 데이터에서조차 상한(+0.79)의 30%</b>에 그쳤다. zero-shot 이전에 학습·손실 설계 문제다.<br>energy 분포 손실이 섭동 신호를 압도한다 — 실제 섭동 효과는 유전자당 0.04 수준인데 세포 간 변이가 훨씬 크다.

리더보드 원시값: PDS 0.5(무작위) / MSE 192 / NMAE 2.643 / FID 0.493 / REACH 0.080 / JAC 0.029.

**교훈: 학습 데이터가 0인 과제에서 대형 모델 학습은 방향이 아니었다.**

#### 1.3 KIMCHI-2 — 조회(retrieval)로 전환

전환의 근거가 된 발견 하나가 판을 바꿨다.

> **300개 타겟 중 272개(91%)가 Replogle 2022 K562 genome-wide 스크린에 이미 측정되어 있다.**

처음에 essential 패널 4개 파일만 확인하고 "300/300이 공개 데이터에 없다 → 일반화 필수"라고<br>결론지었는데, **이것이 틀렸다.** 주최측은 essential 패널과 겹치지 않게 골랐을 뿐,<br>genome-wide에는 대부분 있다. 이 발견 이전에 세운 ESM2 일반화 설계 전체가 불필요했다.

구성:

- 소스 = `data/gwps/K562_gwps_normalized_bulk_01.h5ad` (357 MB, pseudobulk z-score)
- z-score를 **그대로** × 0.567 (`var['std']`를 곱하면 corr +0.29 → +0.09로 붕괴한다)
- 컨텍스트별 fingerprint 가중 — control 프로파일 유사도로 소스 신뢰도를 정함
- 미커버 28개는 covered 델타들의 평균(generic)
- 방출: `expm1(log1p(base) + delta)` → 재정규화 → control 세포의 UMI 총량으로 스케일 → 반올림

결과 **Rank 73, Overall +0.0113.** `fid`가 **−0.326**으로 6지표 중 유일하게 크게 음수였다.

#### 1.4 KIMCHI-3 — 방출(emission) 수정 4종 → Rank 30

**조회 신호는 KIMCHI-2와 완전히 동일하다.** 바꾼 것은 카운트를 만들어내는 마지막 단계뿐이다.<br>이것만으로 +0.0113 → **+0.0876** (73위 → 30위).

| 플래그 | 무엇을 고쳤나 |
|---|---|
| `--stochastic-round` | **결정적 반올림이 응답을 삭제하고 있었다.** 4카운트 유전자에 +4% 응답 → 4.16 → 반올림 4 → 대조군과 바이트 단위로 동일. Wilcoxon이 볼 것이 없다. 소수부 확률로 올리자 `n_pred` 186 → 716, fid 0.436 → 0.572 |
| `--shared-basal` | 타겟마다 basal 400셀을 새로 뽑으면 그 추출 노이즈(유전자당 sd 0.025)가 델타(평균 크기 0.042)와 **같은 자릿수**로 섞인다. 한 번만 뽑아 300 타겟이 공유 |
| `--panel-center 0.6` | 이 패널은 대부분 필수유전자라 반응들이 큰 공통 스트레스 방향을 공유한다. 그 방향은 "어느 유전자를 껐는가"의 정보가 없으면서 모든 쌍의 코사인을 끌어올려 랭킹을 압축한다. 60% 제거로 raw pds 0.790 → 0.869 |
| `--response-dispersion 0.8` | 400셀이 동일 응답이라 호출 수가 예산을 넘었다. 세포별 배율을 lognormal로 흩뜨려 within-group 분산만 키움 |

#### 1.5 KIMCHI-3 이후 알아낸 것 — 진폭이 실제 데이터에서 과하다

리더보드 실측으로 홀드아웃↔실제 **전이율**을 처음 측정했다. 지표마다 다르고, 그 차이에 규칙이 있다.

| 지표 | 홀드아웃 Δ(raw) | 리더보드 Δ(raw) | 전이율 |
|---|---|---|---|
| PDS | +0.0868 | +0.0685 | **79%** |
| FID | +0.1445 | +0.0828 | **57%** |
| REACH | +0.1644 | +0.0391 | **24%** |
| JAC | −0.0380 | +0.0001 | **0%** |
| NMAE | −0.0660 | +0.0107 | **−16%** |

> **규칙: 지표가 유의성 호출 수(<code>n_pred</code>)에 의존하는 정도가 곧 전이 손실률이다.**<br>원인은 검정력 차이다 — 홀드아웃은 200셀 × 8,783유전자, 실제는 400셀 × 18,533유전자.<br>**따라서 홀드아웃에서 호출 수를 튜닝하는 작업은 리더보드로 넘어가지 않는다.**

NMAE만 부호가 뒤집혔다. 실제 컨텍스트는 셀당 중앙값 20,580 UMI로 홀드아웃의 7,642보다 **2.7배 깊다.**<br>같은 델타라도 반올림 손실이 적어 log-FC에 더 크게 반영되고, NMAE는 크기 벌점이므로<br>`--amplitude 1.5`가 실제 데이터에서는 과하다. → **KIMCHI-4가 진폭을 1.0으로 되돌린 arm이다.**

#### 1.6 오라클 분해 — 병목이 어디인지 확정

- `-oracle-real`로 소스 조회 대신 **홀드아웃의 진짜 평균 반응**을 넣고 방출 경로는 그대로 뒀다.<br>이 arm과 replicate 앵커 사이의 간격이 곧 방출 품질 = 어떤 생성 모델이든 벌 수 있는 최대치다.

| 지표 | 현재 최선 | 진짜 평균 + 우리 방출 |
|---|---|---|
| PDS | 0.743 | **1.0000** |
| MSE | 0.000 | **1.0000** |
| REACH | 0.391 | **0.9976** |
| FID | 0.573 | **0.9854** |
| NMAE | 0.083 | 0.6774 |
| JAC | −0.001 | 0.0984 |
| **평균** | **0.298** | **0.7931** |

```
0.298 → 0.793 = 0.50  ← 소스 / 평균 반응 오차   ← 여기가 병목
0.793 → 1.000 = 0.21  ← 방출 품질 (그중 0.18이 JAC 하나)
```

완벽한 평균만 주면 6지표 중 5개가 replicate 수준에 도달하거나 넘어선다.<br>**즉 생성 모델링이 아니라 "어떤 반응을 실을 것인가"가 점수의 2/3를 결정한다.**

남은 방출 여지 0.21은 JAC(전이율 **0%**)과 NMAE(전이율 **−16%**)에 몰려 있다 —<br>리더보드로 가장 안 넘어가는 두 지표다. **방출을 더 파는 것은 홀드아웃 숫자만 올린다.**

#### 2.1 기각한 것과 그 근거 (다시 꺼내지 말 것)

#### 2.2 A. 소스 확대 — **1순위**

현재 소스는 실질적으로 **K562 GWPS 하나**다. 10등권 팀은 8개를 쓴다.

한때 "1등의 함의 상관이 0.347이니 소스는 병목이 아니다"라고 판단했는데 **그건 틀렸다.**<br>0.347은 **소스 측정 자체의 재현성 천장**이지 알고리즘의 한계가 아니다.<br>같은 K562·같은 유전자를 독립 스크린에서 재측정한 재현성이 효과 크기별로 +0.24 / +0.48 / +0.63이고,<br>챌린지 타겟은 K562에서 강한 편이 아니므로 **단일 소스 조회의 천장이 0.35 내외**다.

**소스를 늘려 평균을 내면 그 천장 자체가 올라간다.** 이것이 유일하게 0.50을 줄이는 길이다.

후보:

- **CZI CELLxGENE** 섭동 데이터셋 (상위 팀이 "CZI"를 언급)
- **scPerturb** — 18개 스크린을 확인했으나 미커버 28개는 0개 발견 (커버는 못 늘려도 **평균 내기**에는 쓸 수 있다)
- **같은 300개 타겟을 다른 세포주에서 측정한 소스** — 있으면 fingerprint 가중이 비로소 작동한다
- Replogle RPE1 / Nadig HepG2·Jurkat essential — 커버 0이지만 컨텍스트 정체 추정에는 유효

구현: `retrieval_predict.py`의 조회 계층을 **소스 플러그인 구조**로 리팩터링.<br>각 소스는 `(pert → delta, 유전자축, fingerprint)` 삼종을 내놓고, 상위에서 가중 평균한다.<br>지금은 GWPS가 하드코딩에 가깝다.

**10/22 test set 대비 보험이기도 하다.** 새 300개 패널에서 커버리지가 91%에서 절반으로<br>떨어지면 소스 확대가 주력이 된다.

#### 2.3 B. 그래프 기반 미커버 예측 — **2순위, 이미 절반 완성**

미커버 28개 중 **26개는 GWPS에 유전자(열)로도 없다** (K562에서 발현되지 않아서).<br>따라서 스크린 내부에서 유도한 유사도는 정의되지 않고, **외부 그래프만** 쓸 수 있다.

| 특징 공간 | 미커버 28개 커버 | 고유 성분 상관 (k=50) | 무작위 대비 |
|---|---|---|---|
| **GO** | 27/28 | **+0.183** | **17×** |
| **STRING** | **28/28** | +0.160 | 15× |
| ESM2 | 28/28 | +0.081 | 7× |
| 무작위 | — | +0.011 | — |

> **결정적 조건: 양쪽에서 패널 평균을 뺀 뒤 재야 한다.** 중심화 전에는 모든 특징 공간이<br>무작위와 구별되지 않았다 — 공통 스트레스 방향이 판별을 덮기 때문이다.<br>이 현상을 하루에 두 번(채점기의 `--panel-center`, 이 벤치마크) 서로 다른 곳에서 만났다.

- `-uncovered graph`로 구현되어 KIMCHI-4/5에 이미 들어가 있다 (홀드아웃 avg +0.0093).

남은 일:

- **GO + STRING 결합** (28/28 완결, 두 신호의 독립성 미확인)
- `-go-k` / `-go-weight` 튜닝 (현재 50 / 1.0, 미튜닝)
- **커버리지 붕괴 시나리오 평가** — 인위적으로 50%를 숨기고 재면 10월 대비가 된다

#### 2.4 C. 진폭·컨텍스트 재보정 — **저비용, 즉시**

- **진폭은 홀드아웃이 아니라 depth를 맞춘 조건에서 스윕해야 한다.** 홀드아웃 컨텍스트를<br>실제와 같은 20k UMI로 서브샘플링하거나, 진폭만큼은 리더보드 제출로 직접 확인한다
- **컨텍스트별 파라미터.** 현재 A/B/C에 같은 값을 쓴다. K562 fingerprint가 A=0.478, B=0.351,<br>C=0.365로 다르고 depth도 다르므로 dispersion·amplitude 최적점이 컨텍스트마다 다를 수 있다
- **KIMCHI-4 또는 5를 제출**해 §1.5 진폭 가설을 실측하는 것이 이 항목의 첫 단계다

#### 2.5 D. 하지 말 것

- **홀드아웃에서 호출 수(<code>n_pred</code>) 튜닝** — 전이율 0%. JAC 회수 시도는 여기 해당한다
- **방출 추가 개선** — 남은 0.21이 전이 안 되는 두 지표에 몰려 있다

### 5. 반복하지 말아야 할 실수

1. **실행 중인 셸 스크립트를 수정하지 않는다.** bash가 파일을 다시 읽어 죽는다.<br>이틀에 걸쳐 **두 번** 같은 실수를 했고 두 번 다 30분 이상을 날렸다
2. <b>`pgrep -f`<b></b>가 자기 자신을 매칭한다.</b> 대기 루프는 프로세스가 아니라 <b>산출물 파일 존재</b>로 판단할 것
3. **동시 실행 상한 8개.** gpudge 기본값이 전체 코어라 load average가 372까지 갔다. `CE2_THREADS=12`
4. **결과를 내기 전에 채점 도구부터 맞춘다.** `cell-eval` v1로 며칠 최적화했는데 실제는 `cell-eval2`였고,<br>v1에는 log-FC 크기 벌점이 없어 **결론이 뒤집혔다**
5. **소스 커버리지는 genome-wide까지 확인한다.** essential 패널 4개만 보고 "0/300"이라 결론지었으나<br>실제로는 **272/300**이었다. 이 하나가 접근 전체를 바꿨다
6. **반응 프로파일을 비교할 때는 공통 성분을 먼저 제거한다.** 안 그러면 음성 결과가 데이터가 아니라<br>측정 방식에서 나온다
7. **홀드아웃 스케일 점수를 리더보드 예측치로 쓰지 않는다.** FID의 0점 앵커가 **27배** 어긋나 있다.<br>비교는 원시값으로, 환산은 "마지막 제출의 실측 리더보드 원시값 + 홀드아웃 원시 변화량"으로만
