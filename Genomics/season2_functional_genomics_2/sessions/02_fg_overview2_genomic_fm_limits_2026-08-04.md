#### **상세정보**

- **게놈 파운데이션 모델의 한계 및 활용**: 김민석은 최근 게놈 파운데이션 모델(Single-cell foundation models)의 한계에 대한 보고가 증가하고 있음을 지적하며, 이러한 모델들을 효율적으로 활용하기 위한 인사이트를 공유하고자 주제를 발제함. scGPT, Geneformer 등 기존 모델들은 제로샷(zero-shot)으로 홍보되지만, 실제로는 다양한 세포 타입을 포함한 대규모 데이터를 사전 학습한 뒤, 하위 태스크(downstream task)에 적용할 때 리니어 리그레션이나 MLP와 같은 프로브(probe)를 추가하여 사용하는 피처 익스트랙터(feature extractor)의 형태로 주로 사용되고 있음.
- **PCA 기반 방법론과 파운데이션 모델의 비교**: 김민석은 사전 학습된 거대 모델 없이 단순한 통계적 기법인 PCA(주성분 분석)로도 기존 파운데이션 모델의 성능을 상회할 수 있음을 주장함. PCA를 활용한 파이프라인(SC-TOP)은 정규화 후 고변이 유전자(HVG)를 선택하고 PCA 압축을 거치는 방식으로 구성됨.
- **SC-TOP 방법론과 데이터 전처리**: SC-TOP 파이프라인은 배치 효과를 최소화하기 위해 유전자 발현량의 순위(rank)를 사용하며, 아노바(ANOVA)를 통해 세포 타입 간 변이가 큰 유전자를 선택하여 노이즈를 제거함. 이는 단순한 비지도 학습을 넘어 클래스 레이블을 사용하는 지도 학습 영역에 해당하지만, 파운데이션 모델 역시 프로빙을 통해 지도 학습을 수행하므로 공정한 비교가 가능함.
- **SC-TOP의 성능 평가 결과**: SC-TOP은 트랜스크립트 포머(Transcriptome-former)의 연구 결과와 비교했을 때, 세포 유형 분류(Macro F1 score) 및 종간 보간(interpolation) 성능에서 오히려 더 우수하거나 대등한 결과를 보임. 또한, 유전자 발현 벡터가 이미 진화적 발달 구조를 담고 있어, 비선형적인 거대 모델을 사용하지 않아도 PCA와 같은 선형 변환으로 충분히 정보를 추출할 수 있음이 시사됨.
- **퍼터베이션(Perturbation) 파운데이션 모델 분석**: 세포에 퍼터베이션을 가한 후 발현 변화를 예측하는 모델들에 대한 논의가 이어짐. 이 모델들은 버추얼 셀(virtual cell) 기능을 지향하지만, 기존의 파운데이션 모델을 단순히 적용할 경우 HVG 선택 방식이나 데이터 분할(split) 방식에서 문제가 발생하며, 실제 퍼터베이션 데이터의 특성을 제대로 반영하지 못하는 경우가 많음.
- **벤치마크 및 모델 비교의 중요성**: 퍼터베이션 모델을 평가하기 위해 ASPC 및 E-distance와 같은 지표가 사용됨. 분석 결과, 모델 구조가 퍼터베이션의 특성을 반영하지 못하면 단순한 머신러닝 베이스라인보다 성능이 떨어질 수 있음. 특히, 모델이 퍼터베이션이 강한 데이터일수록 예측 정확도가 떨어지는 경향이 있음.
- **GEARS 모델의 특징과 성과**: GEARS 모델은 사전 학습된 파운데이션 모델은 아니지만, 유전자 간의 상관관계 그래프를 직접 활용하는 GNN(그래프 신경망) 기반 모델로서 퍼터베이션 예측에서 우수한 성능을 보임. 이는 스케일링 법칙(scaling law)을 믿고 거대 모델을 학습시키는 것보다, 데이터의 특성에 맞는 귀납적 편향(inductive bias)을 설계하는 것이 현재로서는 더 효과적일 수 있음을 시사함.
- **벤치마크 태스크의 적절성에 대한 토론**: 김민석과 Yumin Cheong은 현재 사용되는 벤치마크 태스크들이 너무 단순한 분류 작업에 치중되어 있어, 파운데이션 모델의 진정한 가치를 입증하기 어렵다는 점에 동의함. 파운데이션 모델 연구가 너무 쉬운 태스크를 기준으로 평가되어, 단순 통계 기법보다 우위를 점하기 어려운 상황이 반복되고 있음.
- **개인 연구에서의 PCA 활용 경험**: 김민석은 NASD(비알콜성 간질환) 섬유화 연구를 진행하며 파운데이션 모델 임베딩을 튜닝하는 것보다 단순히 PCA를 수행한 결과가 더 우수한 성능을 보이는 경험을 공유함. 이에 연구자들은 향후 논문 투고 시 리뷰어의 질문에 대비하여 PCA 베이스라인을 미리 수행하고 비교하는 전략이 필요함.
- **향후 연구 방향 논의**: 향후 연구에서는 단순히 기존 벤치마크를 따르는 대신, 공간 전사체(spatial transcriptomics)나 멀티오믹스 등 파운데이션 모델이 비선형적 이점을 가질 수 있는 새로운 환경을 탐색해야 한다는 의견이 제시됨. 또한, 당장 파운데이션 모델의 스케일링 법칙이 성립하기를 기대하기보다는 태스크 특화적인 설계나 새로운 데이터 환경에 집중할 필요가 있음.
