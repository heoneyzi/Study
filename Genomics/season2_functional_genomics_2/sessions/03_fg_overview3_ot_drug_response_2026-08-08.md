**세포 약물 처리 데이터 분석 회의 요점**

2026년 8월 8일, 세포 약물 반응 예측 모델 관련 논문 리뷰 세미나가 진행되었다. 발표자(서진)는 단일세포 퍼터베이션(perturbation) 예측 분야의 핵심 문제와 기존 방법론의 한계를 정리한 뒤, **SIMMONS** 논문의 아키텍처·목적함수·실험 결과를 상세히 소개했다. 이후 참석자 질의응답과 향후 챌린지 참여 계획에 대한 논의가 이어졌다.

**문제 정의 및 핵심 도전 과제**

단일세포 약물 반응 예측은 다음 세 가지 구조적 난제를 안고 있다.

- **분포 대 분포 비교**: 실험 데이터는 처리 전후의 ‘단일 세포’가 아니라 대조군 집단과 처리군 집단이라는 두 분포로 존재하므로, 지도 학습이 아닌 분포 간 비교 방식이 필수적이다.
- **세포 이질성(heterogeneity)**: 동일 약물·조건에서도 세포 반응이 달라 평균 이동만 모델링하면 약물 내성과 같은 희귀 세포 상태를 구조적으로 놓치게 된다.
- **미학습 조건 일반화**: 임상적으로 의미 있는 예측은 처음 보는 약물에 대한 것인데, 기존 방법 대부분은 예측 대상 조건의 데이터를 요구해 실용 가치가 제한된다.

**기존 방법론 비교**

**SGGen**

잠재 공간(latent space)에서 오토인코더로 세포를 인코딩한 뒤, 퍼터베이션 효과를 이동 벡터 <b>델타(Δ = 처리 후 평균 − 처리 전 평균)</b>로 표현한다. 세포 타입 A의 델타를 세포 타입 B에 더해 반응을 예측하는 방식이다. 그러나 델타 계산에 해당 퍼터베이션의 사전 관측이 필요해 새 약물에는 적용할 수 없고, 분포의 평균 이동 중심으로 계산하기 때문에 세포 이질성에 취약하다.

**ChemCPA**

CPA(Compositional Perturbation Autoencoder)를 확장한 모델이다. Adversarial 학습으로 세포 표현에서 약물·용량 정보를 분리한 뒤, 디코딩 단계에서 재결합해 미관측 조합을 생성한다. 기존 CPA의 룩업 테이블 방식 약물 임베딩을 **SMILES** (화학식을 텍스트로 표현한 구조 인코더) 기반 임베딩으로 교체해 미관측 화합물도 처리 가능하게 했다.

**CellOT**

잠재 공간 계산을 제거하고, 대조군 분포에서 처리군 분포로의 최적 수송(Optimal Transport) 맵을 신경망으로 직접 학습한다.

**Brenier 정리** (제곱 유클리드 비용에서 OT 맵은 볼록 함수의 기울기)를 활용하며, 볼록성이 구조적으로 보장된 **ICNN** 두 개로 min-max 문제를 푼다. 분포 전체 이동을 모델링한다는 장점이 있으나, 고차원에서의 비현실적인 계산 비용, ICNN 학습 불안정성, 그리고 **비조건부(unconditional)** 설계로 인한 한계(새 조건 예측 불가·조건별 별도 모델 필요·연속 변수(용량) 미활용·크로스 조건 학습 불가)가 존재한다.

**SIMMONS 모델**

**핵심 아이디어**

기존 OT는 조건(약물·용량)마다 별도 모델 **V_i**를 요구하는 반면, SIMMONS는 단일 모델 **T_θ**가 조건 벡터 **C**를 입력으로 받아 학습 중 미관측 조건에도 동일 모델을 적용한다.

**아키텍처**

포워드 패스는 단순하다. 소스 셀 표현 <b>S_i</b>와 조건 벡터 <b>C_i</b>를 연결(concat)해 GELU 활성화 함수를 사용하는 MLP <b>T_φ</b>에 입력하면 시프트 벡터 <b>V_i</b>가 출력된다. 최종 수송 샘플은 <b>\$T_i = S_i + V_i\$</b>로 계산된다.

**V_i가 조건뿐 아니라 세포 상태 S_i에도 의존**하므로 동일 약물·용량에서도 세포별로 다른 반응을 표현할 수 있다. 고차원 유전자 발현 데이터는 오토인코더로 저차원 잠재 표현으로 변환한 뒤 수송을 수행한다.

**조건 임베딩**

- **용량**: 로그 변환 후 사용
- **약물 임베딩 (두 종류)**:
    - **RDKit 임베딩**: SMILES 화학 구조에서 194차원 분자 특징(원자 타입, 결합, 공식 전하, 원자 질량 등)을 추출한다. 약물 구조만 있으면 계산 가능해 완전한 제로샷 예측에 적합하며, 가상 스크리닝(virtual screening)에 핵심적이다.
    - **MOE 임베딩**: 해당 약물을 처리한 실제 세포 데이터 기반 임베딩이다. 성능 상한선 역할을 하지만 사전 실험 데이터가 필요해 완전한 제로샷으로 보기는 어렵다.
- <b>조합 처리(combination treatment)</b>: 각 약물을 동일 인코더로 인코딩한 뒤 <b>딥셋(DeepSet) 형태의 평균 풀링(average pooling)</b>으로 집계해 순서 불변성을 확보하고, 고차 조합으로 자연스럽게 확장된다.

**목적 함수**

목적 함수는 두 항으로 구성된다.

- **Sinkhorn Divergence**: 예측 분포와 실제 타겟 분포 간 차이를 측정한다.
- **Monge Gap 정규화**: 분포만 맞추면 세포를 비현실적으로 멀리 이동시켜도 허용되는 문제를 방지하고, 수송 맵이 최적 수송에 가까워지도록 정교화한다.

학습 시 여러 퍼터베이션 조건을 동시에 샘플링해 동일 모델 파라미터 θ를 업데이트하므로, 약물 A와 B를 별개의 태스크가 아니라 하나의 모델 내 관계로 학습한다.

**데이터셋 및 평가**

- **Sciplex 데이터셋**: 유전자 발현, 3개 세포주, 187개 화합물, 4개 용량 → 총 748개 약물-용량 조합
- **OI 데이터셋**: 단백질 측정 데이터, 다중 약물 조합 처리 포함
- **평가 지표**: R² (특징 정확도), Wasserstein-2 / MMD (분포 유사도)
- **평가 구분**: IS(학습 중 관측 조건) / OS(미관측 용량·약물)

**주요 실험 결과**

- 기존 OT는 9개 약물 × 4개 용량 = **36개 모델**이 필요했으며, 용량 정보가 없으면 R²가 0.694까지 하락한다. SIMMONS는 용량을 조건으로 입력하면 R²가 **0.974**로 회복되고, 조건별 OT(0.978)와 거의 동등한 성능을 **9개 모델**만으로 달성한다.
- 리브-원-드러그-아웃(leave-one-drug-out) 실험에서 10,000 nM 기준 MMD는 SIMMONS MOE **0.013**, SIMMONS RDKit **0.020**, ChemCPA **0.195**로, 분포 메트릭에서 큰 격차를 보인다.
- 748개 약물-용량 조건으로 학습 데이터를 확장하면 RDKit 기반 성능이 MOE 수준에 근접해, **충분한 퍼터베이션 학습 시 화학 구조만으로도 미학습 약물 반응 예측이 가능함**을 시사한다.
- 예측된 유전자 발현에서 실제 **MAPK 관련 경로**도 상당 부분 재현되었다.

**논문의 기여 및 한계**

**기여 6가지**: ① 조건부 OT 실현(Sinkhorn + Monge Gap 정규화), ② 분포 전체 이동 모델링, ③ 화학 구조만으로 미학습 약물 예측, ④ 귀납적 일반화(inductive generalization) 해결, ⑤ 세포 타입·유전자 스크린·시간 등 임의 변수로 확장 가능(CAR-T 설계에 프로테인 언어 임베딩 조건 적용 사례 포함), ⑥ 딥셋 풀링으로 고차 조합 처리 자연스럽게 확장.

**한계**: ① 최고 성능 방법(MOE)은 예측 약물의 효과 정보를 이미 사용, ② INT 베이스라인이 강해 효과 크기가 작으면 개선 여지 협소, ③ 성능이 학습 데이터 내 유사 약물과의 효과 유사도에 강하게 의존, ④ 10,000 nM 등 강한 퍼터베이션은 학습 분포 지지(support) 밖 상태를 유도해 예측이 어려움, ⑤ 평균 풀링은 고차원 약물 상호작용 포착에 한계(어텐션 풀링 시도했으나 성능 개선 미미), ⑥ 완전히 새로운 세포주·노이즈·배치 효과 미처리.

**질의응답 주요 내용**

- **조건 벡터 C의 역할**: 학습·예측 모두 소스 셀 상태 S_i와 조건 C_i를 concat해 동일 모델에 입력한다. 조건을 인수로 받는 구조 덕분에 미관측 조건 C에도 모델을 그대로 적용할 수 있다.
- **RDKit vs. MOE**: RDKit은 화학 구조 기반으로 사전 데이터가 필요 없고, MOE는 실제 세포 반응 기반으로 사전 데이터가 필요하다. 두 임베딩은 별도 모델로 운용되며 멀티모달 결합 방식은 아니다. MOE는 성능 상한 기준선, RDKit은 제로샷 실용성 검증 대상이다.
- **Monge Gap과 목적 함수 결합 방식**: Sinkhorn Divergence와 Monge Gap을 람다 가중치로 결합한 단일 손실 함수로 학습하며, R²·W2·MMD는 학습 후 별도 평가 지표로 관찰된다.
- **OT 가정의 타당성**: 약물 투여 후 세포 분포 변화가 최적 수송 경로를 따른다는 가정에 의문이 제기되었다. 퍼터베이션 분야의 **null theory**(유전자 수가 많아 전체적으로 효과가 희석됨)에 근거가 있으나, 무조건 최선이라 단정하기는 어렵다는 데 공감대가 형성되었다.
- **조합 약물 처리의 한계**: 평균 풀링은 독립적 메커니즘을 건드리는 약물 조합에는 일리가 있으나, 동일 메커니즘 경쟁 결합·약물 간 직접 상호작용·간 대사 변화 등 고차 상호작용 모델링에는 부족하다. 어텐션 풀링이 시도되었으나 조합 퍼터베이션 데이터 자체가 부족해 학습 효과가 제한적이며, 최소한 파인튜닝용 데이터라도 필요하다는 의견이 제시되었다.
- **임베딩 차원(50차원)**: 인풋·아웃풋은 1,000차원이지만 중간 압축은 50차원으로 이루어진다. 유사 태스크에서 64\~128차원 사용 사례가 공유되었으며, 데이터 수보다 데이터 차원 자체가 임베딩 크기 결정에 더 중요하다는 의견이 제시되었다. 전체 변동의 약 80%를 설명하는 수준의 저차원 모델로도 실용적 성능이 가능하다는 데 동의가 이루어졌다.
